## 🚀 Overview

This repository contains the interactive presentation portal and complete marketing dossier for the launch of **ICHITAN OAT MILK**, proposed to Khun Tan Passakornnatee (CEO) and the Executive Committee of **ICHITAN GROUP PLC**.

### Key Strategic Pillars:
1. **The Disruption**: Bringing oat milk out of high-end cafes (110–130฿/liter) to every 7-Eleven shelf across Thailand at **20–25 THB**.
2. **The 3 Product Lines**:
   - **Concept A: Daily Oat (โอ๊ตมิลค์มหาชน - 20฿)**: Mass RTD leader, 0% sugar, lactose-free everyday breakfast nutrition.
   - **Concept B: Oat Tea Lab (ชาพรีเมียมผสานโอ๊ตมิลค์ญี่ปุ่น - 25฿)**: Leveraging Ichitan's green tea heritage (Shizuoka & Uji Matcha) with creamy oat foam.
   - **Concept C: Oat-Pop Vibe (โอ๊ตป๊อป ตัวตึง - 25฿)**: Gen-Z street pop culture with decadent guilt-free dessert flavors (Belgian Dark Cacao, Salted Caramel).
3. **Interactive Features**:
   - **3D Packaging Simulation**: Responsive packaging models with live flavor switcher and tilt animation.
   - **Market War-Map & Charts**: Real-time canvas charts comparing pricing and market trajectory.
   - **Interactive CEO Profit Simulator**: Real-time financial calculations (Volume, ARR, Margin, EBITDA).
   - **Executive Board Voting Console**: Interactive scoring matrix and official resolution generator.
   - **Boardroom Presentation Deck Mode**: Fullscreen slide-by-slide mode for projectors.

## 💻 Tech Stack
- **Frontend**: Clean Semantic HTML5, Custom Executive CSS3 (Glassmorphism, 3D CSS Transforms), Modern Vanilla JS (ES6+).
- **Charts**: Retina-ready canvas visualizations (Zero external dependencies).
- **Server**: Lightweight Node.js static server (`server.js`).

## 🛠️ Local Development & Running

To run locally:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
